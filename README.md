# SkyHouse

Sky's house luxury catalog website.

- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion
- Supabase-ready admin scaffold
- Vercel-ready
- GitHub -> Vercel automatic deployments enabled

Product images are temporarily served from the previous immutable Vercel deployment until they are migrated to Supabase Storage.
